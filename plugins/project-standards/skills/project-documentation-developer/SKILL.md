# Project Documentation Developer

Read `references/documentation-model.md` and `references/documentation.md`. Read `references/script-catalog.md` when a root entrypoint or script catalog is affected.

Route stable architecture and domain contracts to `DESIGN.md` or `design/**`, maintained operational and user material to `docs/**`, and normative engineering rules to `AGENTS.md`.

Do not create empty documentation roots, forwarding documents, compatibility paths, or a second owner for the same contract. Preserve semantics before deleting a source.
