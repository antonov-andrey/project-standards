# AWS CloudFormation Developer

Read `references/aws-cloudformation.md` completely.

Keep account, region, ownership, least-privilege production semantics, development authorization, cost exposure, lifecycle, rollback, and observable acceptance explicit. Validate templates and inspect change sets before production execution.

Never infer production write authority from development-account authority.
